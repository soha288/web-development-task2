# ⏱️ Stopwatch Web Application

This is Task-02 of my internship at **Prodigy Infotech**. I built a stopwatch web application using **HTML**, **CSS**, and **JavaScript**. The app can start, pause, reset, and track lap times.

## 🚀 Features

- Start/Pause Stopwatch
- Reset Stopwatch
- Record Lap Times
- Clean and Responsive UI

## 🛠️ Tech Stack

- HTML
- CSS
- JavaScript
📝 About the Internship

This project was developed as part of my Web Development Internship at Prodigy Infotech. It helped me strengthen my skills in frontend technologies and real-time UI interactions.
